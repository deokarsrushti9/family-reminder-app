# Family Reminder App 👨‍👩‍👧‍👦⏰

A Family Reminder Application built using modern web technologies to help family members stay connected through reminders, notifications, and shared tasks.

---

## 🚀 Features

- Create reminders easily
- Assign reminders to family members
- User-friendly interface
- Reminder notifications
- Responsive design
- Authentication system
- Dashboard for managing reminders

---

## 🛠️ Tech Stack

- React / Vite
- TypeScript
- CSS
- Node.js
- Local Storage / Backend API

---

## 📂 Project Structure

```bash
src/
 ├── components/
 ├── pages/
 ├── styles/
 ├── assets/
 └── App.tsx
```

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/deokarsrushti9/family-reminder-app.git
```

Go to project folder:

```bash
cd family-reminder-app
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
